## 🚀 Why use these snippets?
Building websites with page builders often comes with visual and layout limitations. Instead of installing extra third-party add-ons that bloat your site and hurt technical SEO (Core Web Vitals), you can use lightweight, clean CSS. Here you will find solutions for:
* Modern navigation menus (Glassmorphism & blur effects)
* Custom styling for WooCommerce buttons and product cards
* Improving mobile responsiveness (RWD) and user experience
* Sleek, minimalist, and modern design aesthetics

## 📁 Folder Structure
The snippets are organized into clear, intuitive categories:
* `/tables` – Fixing gutenderg and html tables. 
* `/elementor-hacks` – Specific modifications for Elementor widgets and sections.
* `/woocommerce-css` – Styling enhancements for online stores and checkout flows.
* `/gutenberg-blocks` – Custom styles for the native WordPress block editor.
* `/animations` – Lightweight hover animations and micro-interactions.

## 💻 How to implement the code?
Most of these snippets are Copy & Paste.
1. Log in to your WordPress Dashboard.
2. Navigate to **Appearance** -> **Customize** -> **Additional CSS**.
3. Paste the copied snippet and hit publish.
