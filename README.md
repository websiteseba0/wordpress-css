# wordpress-css
Personal repository of CSS snippets I use while building WordPress websites for my clients.

I am a WordPress developer with 15 years of experience. My stack is based on Elementor Pro as main framework. I don't use standard templates and creating everything from scratch. But empty WordPress looks quite shitty, so over years I created repository of CSS fix patches that solve most of visual problems while using pure [Elementor PRO](https://elementor.com/products/website-builder/).
